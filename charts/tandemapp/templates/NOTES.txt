   kubectl port-forward: on Kubernetes the pod never trusts its own loopback.
{{- $setup := include "tandemapp.setupSecret" . }}
{{- if $setup }}

     kubectl -n {{ .Release.Namespace }} get secret {{ $setup }} -o jsonpath='{.data.{{ include "tandemapp.setupKey" . }}}' | base64 -d; echo
   Open the page and enter it with the owner's name and password.
{{- if not (.Values.auth.bootstrap | default dict).existingSecret }}
   A release that had an admin token keeps this Secret: the token works once as the setup code,
   and once an owner exists, as an API token for scripts that ends after 30 days.
{{- end }}
   Once the owner exists the health page asks to delete the Secret (bootstrap_secret_left). Keep
   it while you may still roll back to an older release: its admin token signs in there.
{{- else }}
   No setup code Secret: the controller's log has a code at each start while no owner exists.
{{- end }}

   A lost password:    {{ $cli }} users reset-password NAME {{ $db }}
