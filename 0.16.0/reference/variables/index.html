    Reference: variables and knobs¶

    The proxy, the collector and the plugins read TANDEM_* variables. TandemApp's code reads some of the engine's QSE_* variables too, where it starts chatd, runs TandemNode or reads the engine's files. Inside an engine the conductor reads the QWEN38_* knobs the engine contract names (contracts/engine-ext-v1/knobs.json), with the defaults of tandemapp/knobs.py. tools/gen_reference.py builds every table here from the code. The old sign-in's variables, which the first start imports once, are in auth.md.
